# Фильмотека — ДЗ 6. API-витрина

Frontend-клиент для учебного REST API: каталог фильмов с загрузкой, добавлением, редактированием и удалением.

**Ресурс:** `films`
**Endpoint:** `http://localhost:3000/films`

Поля фильма: `title` (строка), `year` (число), `genre` (строка), `rating` (число 1–10), `isWatched` (true/false).

## Запуск API

```bash
cd backend
npm ci
npm run dev
```

После запуска откройте http://localhost:3000/films — вернется JSON со списком фильмов.

## Запуск frontend

1. Откройте папку проекта в VS Code.
2. Правый клик по `frontend/index.html` → **Open with Live Server**.
3. API должен быть запущен.

## Обязательная часть

- загрузка коллекции через GET;
- состояния загрузки, результата, пустого списка и ошибки;
- кнопка «Обновить» повторяет запрос;
- добавление фильма через форму (POST) с HTML-валидацией и блокировкой повторной отправки.

## Дополнительная часть

- **A2** — удаление фильма (DELETE) с подтверждением;
- **A3** — редактирование фильма (PATCH): форма открывается с текущими значениями, отправляются только измененные поля, есть отмена;
- **B2** — оптимистичное удаление: карточка исчезает сразу, при ошибке возвращается на место;
- **B3** — тайм-аут запросов через `AbortController` (5 секунд), отличается от ошибки 404 и остановленного API;
- **C** — общая функция `request` для всех запросов, один массив `films` как источник данных.
